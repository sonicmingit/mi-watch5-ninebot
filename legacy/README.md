# 旧双应用方案（备份）

保留已经验证的旧流程：手表分别安装九号出行 port5 和手表授权助手 0.5；手机安装官方九号与手机授权助手 0.5。此目录保存构建增量、圆屏资源及调试记录，Release 提供对应 APK。

从单包版回退时，安装 `ninebot-watch-legacy-restore-v0.0.9-port5.apk`（原 port5 业务 DEX 和资源，版本码升至 90006 方便同签覆盖），再安装 `ninebot-watch-authorization-v0.5.apk`。无需卸载当前单包或清除数据。之后打开**手表授权助手**点“开始配对”；手机助手填手表显示的 `IP:38766`，两端核对配对码并确认，再打开手机官方九号和手表九号。

旧原版 port5 的 SHA-256 为 `0d396a2c279f669ee876043a9debf987e2159be93207adb50fb1b10ddfb1f169`。恢复包只提高版本码，其两个 DEX 和 `resources.arsc` 与原版完全一致。旧版源码依赖当时工程内的 vendor APK 与工具链，供审阅和追溯；新开发以仓库根 README 的单包方案为主。
